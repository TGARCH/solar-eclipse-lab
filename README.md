# Solar Eclipse Lab

Interaktywna prezentacja 3D Układu Słonecznego i mechanizmu zaćmienia Słońca.

## Stack
- React
- Three.js / React Three Fiber
- Vite
- Vercel

Projekt jest bazą do dalszego pipeline'u: modele GLB oraz dane techniczne pochodzące z IFC.

## Uruchomienie
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Źródłem aplikacji jest gałąź `main` repozytorium GitHub. Każdy push do `main` uruchamia automatyczny deployment na Vercelu.
