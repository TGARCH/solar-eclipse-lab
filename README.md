# Solar Eclipse Lab

Profesjonalne interaktywne laboratorium 3D Układu Słonecznego i zaćmień.

- relacje średnich promieni planet i okresów orbitalnych oparte na danych astronomicznych,
- dwie jawnie opisane skale odległości: czytelna (potęgowa) i względna/astronomiczna (logarytmiczna),
- zaćmienie Słońca i Księżyca z wizualizacją umbry oraz penumbry,
- fizyczne cienie Three.js z punktowego źródła światła,
- kamera globalna i kamera-rig umieszczona w hierarchii Ziemi.

## Uruchomienie

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Źródłem wdrożenia Vercel jest gałąź `main`.
